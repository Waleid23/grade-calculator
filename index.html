How to add work
  • Add a row for every homework and quiz that's been assigned and is due, using + Add.
  • Didn't turn it in? Tick Missing. It counts as 0.
  • Work that hasn't been assigned or isn't due yet: don't add it. It isn't counted.
  • A row left blank also counts as 0 and is flagged until you enter a score or mark it Missing.
