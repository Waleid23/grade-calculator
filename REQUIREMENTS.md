## Grading scale
- 95–100% = 4.0
- Below 95, each percentage point lower drops the grade by 0.1:
  94 = 3.9, 93 = 3.8, 90 = 3.5, 85 = 3.0, 80 = 2.5, 75 = 2.0, 70 = 1.5, 65 = 1.0
- 64% or below = 0.0

So the user's 3.8 goal means an overall grade of 93%.

## Special rules
1. Drop the lowest quiz grade.
2. Late homework is accepted up to 3 days late with a 10% penalty.
3. Missing assignments count as zero.
4. Final grades use weighted averages.
